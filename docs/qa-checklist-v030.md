# v0.3.0 验收清单（QA / M7 专用）

> 每项验收需给出证据（测试输出 / Playwright 截图或断言 / 手工路径）。全部打勾后方可打 tag v0.3.0。

## A. 主界面与菜单

- [ ] 主界面新增「新手教程」按钮，位于「练习模式」按钮上方；点击可进入教程入口（最终版为完整教程，非占位）
- [ ] 「单人模式」已改名「练习模式」；「联机对战」已改名「对战模式」
- [ ] 练习模式页含四个子模式入口：经典模式 / 超快棋模式 / 盲棋模式 / 自定义模式
- [ ] 经典/超快棋/盲棋三入口共用同一套尺寸选择界面：小型（10×10，3 架）/ 中型（15×15，5 架）/ 大型（20×20，7 架）+ AI 难度选择，难度与「设置」界面联动（互改同步）
- [ ] 自定义模式界面含「超快棋模式」「盲棋模式」两项开关，可独立开启，进入对局后规则正确生效（含两者同时开启的组合）
- [ ] 版本角标显示 v0.3.0
- [ ] 竖版 9:16 / 横版均无布局溢出、无滚动条（沿用既有 stage 适配）

## B. 对战模式（联机）

- [ ] 三个板块（经典/超快棋/盲棋）各含「小/中/大」三个独立可勾选项，可多选；默认仅经典模式的小/中/大勾选
- [ ] 「开始匹配」按勾选项组合发起快速匹配（`match:quick { combos }`）；无对手时进入等待态（显示等待中，可取消）
- [ ] 两个玩家勾选项有交集时可自动配对入局；配对房间配置符合所选 combo（尺寸/架数/模式）
- [ ] 「自定义房间」板块：创建房间（含超快棋/盲棋开关）+ 加入已有对局（房间码），功能与 v0.2.10 一致
- [ ] 断线/取消匹配后等待池正确清理（服务端集成测试覆盖）

## C. 超快棋（blitz）

- [ ] 双方初始倒计时 = 10×n 秒（n=架数；3/5/7 架分别为 30/50/70 秒）
- [ ] 己方每成功报点一次 +1 秒
- [ ] 超时一方立即判负（单机弹结算；联机收到 `gameOver { reason: 'blitz-timeout' }`）
- [ ] 剩余 <10 秒时倒计时数字标红并轻微闪烁
- [ ] blitz 下 byo-yomi（每步限时/超时次数/机器代打）不生效
- [ ] 联机时钟由服务端权威驱动（`clock:update`），客户端重连后时钟可恢复或房间判负，无双方显示不一致

## D. 盲棋（blind）

- [ ] 仅该模式允许重复报点：对已报点格（含击毁残骸格）再次报点被接受，残骸仍返回"击空"误导
- [ ] 对手网格仅显示最近 3 个报点标记（FIFO 淘汰）；击毁标记永久保留且不计入 3 个名额
- [ ] 该模式下「允许移动参考飞机」与「着色工具」均被禁用（入口隐藏或置灰，含联机与单机）
- [ ] 非盲棋模式重复报点仍被拒绝（回归验证）

## E. 预报点（替代"对方回合不能报点"提示）

- [ ] 原"对方回合时不能报点"提示已删除
- [ ] 非我方回合点击空网格 → 深红色「?」预报点标记；上限 10，第 11 个提示"预报点已达数量上限"
- [ ] 再次单击预报点选中 + 确认（点击或坐标输入）可取消该预报点
- [ ] 轮到我方回合时，按 FIFO 每回合自动上报一个预报点（队列空恢复手动报点）；自动上报与手动报点对回合消耗一致
- [ ] 预报点不可置于已有标记格；联机下预报点纯客户端，服务端无需感知（回归：对手回合不会发出非法 shot）
- [ ] 教程场景：对手长考时创建的预报点在我方回合自动生效

## F. 快捷着色

- [ ] 设置新增「快捷着色」开关，默认开启并持久化
- [ ] 开启时：着色模式点击空网格中的幽灵飞机 → 批量着色 + 退出着色模式 + 消灭该幽灵飞机
- [ ] 关闭时：点击幽灵飞机仅批量着色，不退出着色模式、不消灭幽灵飞机
- [ ] 联机与单机行为一致

## G. 新手教程（最后制作，全绿后才验收）

- [ ] 入口弹窗："您是否了解本游戏的基本规则？" →「是的」/「还没有」；「是的」直达进阶教程，「还没有」进入基础教程
- [ ] 基础·单元1（摆阵）：欢迎语 → 突显飞机待选栏 → 拖入 1 架 → 拖完 3 架 → 旋转 90° → 阵形合法后突显"确认布阵" → 点击进入单元2（按 \n 逐条推进，对话气泡文本与文案脚本一致）
- [ ] 基础·单元2（对战）：沿用单元1 阵型，10×10 3 架经典模式、我方先手、AI 避开我方机头报点；双击报点教学、击空/击中/击毁分支文案、击毁后提示"对已击毁的飞机报点将显示击空"、胜利收尾
- [ ] 进阶·单元3（工具）：10×10 3 架、我方阵型随机且已被击毁一架、对方先手、AI 避开我方机头；依次教学参考网格（可旋转、可拖成幽灵飞机）→ 我方网格与绝杀规则 → 坐标输入框 → 着色工具（长按选色）→ 着色模式下点击幽灵飞机批量着色（含快捷着色说明）→ 预报点（上限 10、对手长考时创建、我方回合自动上报）
- [ ] 单元2 结束弹窗："基础教程已完成，是否继续进阶教程？" → 返回主页 / 继续教程
- [ ] 单元3 弹窗："进阶教程已完成，是否完成对局？" → 完成教程 / 继续对局（继续对局时对手 AI 恢复正常行动）
- [ ] 对话气泡纸感风格、随文本自动调整大小与位置（竖版在空网格下方、横版在参考网格下方）、不遮挡空网格与当前突显目标
- [ ] 突显遮罩：除突显对象、教程文本、气泡外其余画面变暗
- [ ] 右上角「跳过」可跳过当前单元
- [ ] 教程全程无控制台报错
