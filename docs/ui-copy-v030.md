# 飞机杀 v0.3.0 · UI 文案脚本

> 本文档仅供 UI / 联机 / 教程（M8）实现者引用，规则基线见 `docs/design.md`（以 design.md 为准，本文只补 v0.3.0 新增 UI 文案与教程脚本）。
> 文案语气：纸面、简洁、带一点军棋味；沿用既有语汇（报点 / 击空✗ / 击中◯ / 击毁★ / 摆阵 / 房码 / 幽灵飞机 等），不引入新行话。

## 0. 记号语义（教程脚本通用）

| 记号 | 含义 | 实现说明 |
|---|---|---|
| `\n` | 气泡内强制换行 | 原文换行即气泡断行，渲染时保留 |
| `<>` | 运行时替换值 | 如坐标 <A5>、数量 <n>，按当前局面填充 |
| `[]` | 界面控件/按钮名 | 气泡内出现时按键化/加粗渲染（可点击目标） |
| `突显` | 视觉引导高亮 | 对目标元素加虚线框/发光/缩放提示，教程等待该元素就绪 |

## 1. 主菜单与练习模式

### 1.1 主菜单（三入口）

| 入口按钮 | 说明 |
|---|---|
| `新手教程` | 进入教程选择弹窗（见 §5.2），首启引导 |
| `练习模式` | 单机练习：四子模式 + 尺寸档位（§1.2 / §1.3） |
| `对战模式` | 联机对战：局域网 / 公网匹配 / 自定义房间（§2） |

> 主菜单页脚保留既有 `规则说明` 入口与版本角标（现文案）。

### 1.2 练习模式 · 四子模式

| 子模式按钮 | 一行说明 | 备注 |
|---|---|---|
| `经典模式` | 常规对局：先摆阵，再随机先后手轮流报点。 | 无步时限制，等同既有单机对局 |
| `超快棋模式` | 10n+1 限时，超时判负。 | n 取值待组长定夺（建议：n=飞机架数，供参考），超时无读秒机会、直接判负 |
| `盲棋模式` | 不记旧报点，禁参考飞机与着色。 | 局内隐藏报点记录；着色工具与参考飞机不可用（提示见 §4） |
| `自定义模式` | 自定棋盘尺寸与飞机形状，全部校验通过才可开战。 | 进入既有自定义配置页 |

### 1.3 尺寸档位（经典 / 超快棋 / 盲棋三模式共用）

| 按钮文案 | 副文案 | 数值 |
|---|---|---|
| `小型` · 10×10 | 3 架飞机 · 新手友好 | 10×10，3 架 |
| `中型` · 15×15 | 5 架飞机 · 标准体验 | 15×15，5 架 |
| `大型` · 20×20 | 7 架飞机 · 持久战 | 20×20，7 架 |

### 2.3 自定义房间 · 模式开关（超快棋 / 盲棋）

| 开关标签 | 说明文案 | 默认 |
|---|---|---|
| `超快棋` | 开启后按 10n+1 限时，超时判负。 | 关 |
| `盲棋` | 开启后不记旧报点，双方禁参考飞机与着色。 | 关 |

> 说明：两个开关可独立选择；与既有「每步限时」「允许对战双方移动参考飞机」等配置并存，规则冲突（如盲棋 + 允许移动参考飞机）时以盲棋禁用为准，勾选处给出提示（§4）。

## 5. 新手教程脚本

> 下方按「可执行步骤表」给出，供 M8 直接翻译成教程状态机。每步的 `突显` 目标、`[]` 控件、`\n` 换行、`<>` 动态值均保留语义（§0）。原文对话气泡文本汇总见 §5.7（实现时以 §5.7 的文本为准，步骤表负责触发顺序）。

### 5.1 教程流程总览

| 阶段 | 内容 | 场景 |

| 教程·基础 单元2 | 对战基本流程 | 沿用单元1阵型开局 |
| 基础完成弹窗 | 是否继续进阶 | — |
| 教程·进阶 单元3 | 实用工具教学 | 固定脚本对局 |
| 进阶完成弹窗 | 是否完成对局 | — |

### 5.3 教程·基础

**单元1 · 学习摆放飞机（10×10 三架摆阵）**

| # | 触发 | 文案 / 引导 | 实现注释 |
|---|---|---|---|
| T1-1 | 进入摆阵 | `欢迎，指挥官。\n我们从摆飞机开始——把 3 架飞机放到 10×10 的棋盘上。` | 欢迎语，等待任一步操作后进入下一步 |
| T1-2 | T1-1 后 | 突显 `飞机待选栏`；气泡：`下方[飞机栏]里共有 3 架飞机，把它们一架架拖上棋盘。` | 高亮待选栏；拖拽期间不阻塞 |
| T1-3 | 第一架拖上棋盘 | `很好，第一架就位。\n点一下飞机可以旋转 90°，试试把下一架转个方向。` | 首次旋转后进入 T1-4 |
| T1-4 | 3 架全部就位 | `3 架都摆好了。\n旋转、拖拽都随心——摆位没有对错。` | 判定：3 架全部落在合法格 |
| T1-5 | 阵形合法（校验通过） | 突显 `确认布阵`；气泡：`阵形合法，[确认布阵] 已点亮——点击它开始对局。` | 仅当校验通过才突显；点击后进入单元2 |
| T1-6 | 点击确认布阵后 | `对局开始！\n顺带一提：这局你是先手。` | 切到对战界面后进入单元2 引导 |

**单元2 · 对战基本流程（沿用单元1 阵型；我方先手；AI 避让机头）**

| # | 触发 | 文案 / 引导 | 实现注释 |
|---|---|---|---|
| T2-1 | 我方回合 | `双击对手棋盘上的格子，或在下方的输入框输入坐标后按回车，即可报点。` | 等待我方完成第一次报点 |
| T2-2 | 我方报点完成 | `干得好。对手的回合通常要等一会儿——趁这时间想想下一击。` | 进入等待 |
| T2-3 | 对方（AI）报点：击空 | 随局内反馈显示 `对方报点 <坐标>：击空！`；气泡补一句：`击空 = 该格没有飞机，会画上 ✗。` | AI 报点统一落在非机头格，避免过早结束教程 |
| T2-4 | 我方命中非机头 | `命中非机头 → ◯ 击中；命中机头 → ★ 击毁。继续找机头！` | 教学击空/击中反馈后提示机头 |
| T2-5 | 我方或对方出现击毁 | `击毁一架后记得：对已击毁的飞机其余格位报点，会显示"击空"。` | 残骸误导规则一句话带过 |
| T2-6 | 胜利（AI 全灭） | `对方 3 架全灭——本局获胜！\n基础部分到此为止。` | 胜利结算后弹出 P4 |

> AI 行为约束（实现注释）：单元2 全过程中 AI 报点避开我方机头，且不主动击毁我方飞机，保证我方至少能完成 3 次以上操作。

### 5.5 教程·进阶

**单元3 · 实用工具（10×10 三架；我方阵型随机且已被击毁 1 架；对方先手；AI 避让机头）**

| # | 触发 | 文案 / 引导 | 实现注释 |
|---|---|---|---|
| T3-1 | 进入对战（对方先手） | `这一局换一种玩法：让我方先熟悉一下界面上的工具。` | 对方先手，等对方完成 1 次报点（击空）后进入 T3-2 |
| T3-2 | 对方报点后 | 突显 `参考网格`（5×5 样式参考飞机）；气泡：`左上角的[参考网格]是你的样式参考飞机：点它可旋转 90°，按住可拖到对手棋盘上辅助推演。` | 高亮参考网格区 |
| T3-3 | 拖出参考飞机 | `拖出棋盘会变成半透明的[幽灵飞机]，随指针移动——松手即放置，随时可再拖。` | 解释幽灵飞机 |
| T3-4 | T3-3 后（或拖放一次后） | 突显 `我方网格`；气泡：`这是我方网格。被击毁的飞机只会在这里暗色标出——对方看不到，残骸与空格在他眼里没有区别。` | 讲解我方视角信息差；此时局内已击毁我方 1 架 |
| T3-5 | T3-4 后 | `把对方全部飞机击毁即获胜；若一轮内你全歼对方、自己又只剩 1 架，将触发[绝地反击]：对方获一次额外报点。` | 绝杀规则一句话带过 |
| T3-6 | T3-5 后 | 突显 `坐标输入框`；气泡：`底部输入框可键入坐标（如 <B7>）按回车报点，与双击等效。` | 不强制操作，允许跳过 |
| T3-7 | T3-6 后 | 突显 `着色工具按钮`；气泡：`[着色笔]：点按进入着色模式；长按约 0.5 秒调出调色板（黄/蓝/绿）。` | 长按弹色板教学 |
| T3-8 | 完成一次选色后 | `着色模式下点按或拖拽棋盘格即可涂色——随你标记。` | 涂色教学 |
| T3-9 | 完成一次涂色后 | `现在试试对着[幽灵飞机]点击：整架会被批量着色，同时幽灵飞机回收回参考网格。` | 快捷着色教学；如失败提示见 §4 |
| T3-10 | T3-9 后 | 突显 `预报点` 说明；气泡：`[预报点]：对手长考时可以提前点好想打的格子，最多 10 个；\n轮到自己时这些预报点会自动上报，无需再点。` | 预报点教学（上限 10、自动上报） |
| T3-11 | 完成教学序列 | `这些就是全部实用工具。接下来，用它们赢下这局吧。` | 等待对局自然结束或玩家结束 |

> 对局说明（实现注释）：单元3 结束时若对局未结束，玩家可继续；进阶完成弹窗见 P6。
