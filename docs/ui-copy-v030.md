# 飞机杀 v0.3.0 · UI 文案脚本

> 本文档仅供 UI / 联机 / 教程（M8）实现者引用，规则基线见 `docs/design.md`（以 design.md 为准，本文只补 v0.3.0 新增 UI 文案与教程脚本）。
> 文案语气：纸面、简洁、带一点军棋味；沿用既有语汇（报点 / 击空✗ / 击中◯ / 击毁★ / 摆阵 / 房码 / 幽灵飞机 等），不引入新行话。
> 教程气泡文本以用户手稿原文为准（§5），任何润色须经组长确认。

## 0. 记号语义（教程脚本通用）

| 记号 | 含义 | 实现说明 |
|---|---|---|
| `\n` | 气泡内强制换行 | 原文换行即气泡断行，渲染时保留 |
| `<>` | 运行时替换值 | 如坐标 <A5>、数量 <n>，按当前局面填充 |
| `[]` | 界面控件/按钮名 | 气泡内出现时按键化/加粗渲染（可点击目标） |
| `突显` | 视觉引导高亮 | 对目标元素加虚线框/发光/缩放提示，教程等待该元素就绪 |
| `／` | 手稿气泡内分段 | 手稿用全角「／」分隔同一气泡/连续提示的多句文本，逐句展示节奏由实现方决定，文字不增删 |
| `*…*` | 手稿强调记号 | 手稿原样保留星号（如 `*击空*`），渲染为强调/加粗 |

## 1. 主菜单与练习模式

### 1.1 主菜单（三入口）

| 入口按钮 | 说明 |
|---|---|
| `新手教程` | 进入教程选择弹窗（见 §5.2），首启引导 |
| `练习模式` | 单机练习：四子模式 + 尺寸档位（§1.2 / §1.3） |
| `对战模式` | 联机对战：局域网 / 公网匹配 / 自定义房间（§2） |

> 主菜单页脚保留既有 `规则说明` 入口与版本角标（现文案）。

### 1.2 练习模式 · 四子模式

| 子模式按钮 | 一行说明 | 备注 |
|---|---|---|
| `经典模式` | 常规对局：先摆阵，再随机先后手轮流报点。 | 无步时限制，等同既有单机对局 |
| `超快棋模式` | 10n+1 限时，超时判负。 | n=飞机架数（每步限时 10×n 秒起步、每步 +1 秒，已定稿）；超时无读秒机会、直接判负 |
| `盲棋模式` | 不记旧报点，禁参考飞机与着色。 | 局内隐藏报点记录；着色工具与参考飞机不可用（提示见 §4） |
| `自定义模式` | 自定棋盘尺寸与飞机形状，全部校验通过才可开战。 | 进入既有自定义配置页 |

### 1.3 尺寸档位（经典 / 超快棋 / 盲棋三模式共用）

| 按钮文案 | 副文案 | 数值 |
|---|---|---|
| `小型` · 10×10 | 3 架飞机 · 新手友好 | 10×10，3 架 |
| `中型` · 15×15 | 5 架飞机 · 标准体验 | 15×15，5 架 |
| `大型` · 20×20 | 7 架飞机 · 持久战 | 20×20，7 架 |

### 2.1 三板块标题

| 板块 | 标题文案 | 说明 |
|---|---|---|

### 2.2 操作按钮与状态文案

| 场景 | 文案 | 说明 |
|---|---|---|
| 公网匹配主按钮 | `开始匹配` | 沿用 |
| 匹配等待中 | `正在匹配对手…` | 可加副行：`（30 秒内未匹配上，可自建房间邀请好友）` |
| 匹配取消 | `取消匹配` | 点击后离开匹配队列 |
| 局域网建房间 | `创建房间` | 沿用 |
| 局域网加入 | `加入已有对局` | 房主分享 6 位房码；输入框占位 `房码`（沿用） |
| 自定义房间入口 | `配置并创建自定义房间` | 沿用 |

### 2.3 自定义房间 · 模式开关（超快棋 / 盲棋）

| 开关标签 | 说明文案 | 默认 |
|---|---|---|
| `超快棋` | 开启后按 10n+1 限时，超时判负。 | 关 |
| `盲棋` | 开启后不记旧报点，双方禁参考飞机与着色。 | 关 |

> 说明：n=飞机架数（每步限时 10×n 秒起步、每步 +1 秒），已定稿，与 §1.2 一致。两个开关可独立选择；与既有「每步限时」「允许对战双方移动参考飞机」等配置并存，规则冲突（如盲棋 + 允许移动参考飞机）时以盲棋禁用为准，勾选处给出提示（§4）。
